# Prática de Embeddings com Ollama e Python

Este repositório contém a atividade prática de geração de embeddings utilizando o **Ollama** e a linguagem **Python**.

## Tecnologias Utilizadas
- **Python 3**
- **Ollama** (Modelo: 'mxbai-embed-large')
- **Git / Github**

## Como executar o Projeto Localmente

1. Certifique-se de ter o **Ollama** instalado e rodando em sua máquina local.
2. Instale a biblioteca do Ollama para Python:
   
   'pip install ollama'
   
3. Execute o script principal:
   
   'python embeddings.py'

# Resultado Esperado

O script processa uma string de entrada e exibe no console um vetor de embeddings de 1024 dimensões gerado localmente pelo modelo.
